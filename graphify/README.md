# Graphify Engine

Graphify is a machine-readable graph intelligence engine that converts repository information, dependencies, rendering trees, and data models into visual Mermaid diagrams and structured schema graphs.

## Structure

```
/graphify
├── README.md               # Engine overview & entrypoint
├── schema.md               # Graph JSON / Markdown schema contract
├── graph-rules.md          # Architectural relationship rules
├── node-types.md           # Node definitions & entities
├── edge-types.md           # Edge relationships & directional semantics
├── visualization.md        # Mermaid & SVG visualization guidelines
└── generated/              # Auto-generated codebase visual graph outputs
    └── system-graph.md     # Full codebase system graph
```
