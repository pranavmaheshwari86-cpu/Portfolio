# Node Types Definition

|---|---|---|---|

| **Module** | 📦 | Data or state module | `portfolioData.ts` |
| **Component** | 🧩 | UI React component | `Navbar.tsx`, `Hero.tsx`, `About.tsx` |
| **Function** | ⚡ | Utility or callback function | `onOpenContact`, `onComplete` |
| **API Endpoint** | 🌐 | Endpoint or external URL anchor | `mailto:Pranavmaheshwari86@gmail.com` |
| **External Dependency** | 📚 | Third-party npm library | `framer-motion`, `canvas-confetti`, `lucide-react` |
| **Configuration** | ⚙️ | Build/tool config file | `vite.config.ts`, `package.json` |
