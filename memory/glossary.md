# Technical Glossary

| Term | Definition |
|---|---|
| **SPA** | Single Page Application — web app that loads a single HTML page and dynamically updates content. |
| **Glassmorphism** | UI design trend utilizing translucent frosted-glass backgrounds with backdrop blur. |
| **Framer Motion** | Motion library for React that simplifies declarative animations and layout transitions. |
| **Oxlint** | Rust-based static code linter designed for high-speed JS/TS code checking. |
| **Tree-Shaking** | Build optimization technique that removes unused code from final bundle. |
| **HMR** | Hot Module Replacement — updates modules in running application without full page reload. |
