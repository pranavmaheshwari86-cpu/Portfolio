# Project Overview

## Summary
`portfolio-new` is a high-performance, dark-themed luxury developer portfolio and engineering showcase built for **Pranav** (FullStack Engineer & AI Engineer). The application features smooth Framer Motion micro-interactions, an interactive process timeline, selected work showcases, custom confetti triggers, a responsive contact modal, and a preloader.

## Core Features
1. **Fullscreen Preloader**: Animated initial loading screen with percentage counter and completion callback.
2. **Floating Navbar**: Glassmorphism sticky navigation header with smooth scrolling links and "Hire Me" contact modal trigger.
3. **Hero Section**: High-impact personal branding section featuring dynamic role display, call-to-action buttons, resume download, and interactive contact triggers.
4. **About Me Section**: Technical profile detailing experience (5+ years), tech stack cards (React.js, Node.js, MongoDB), and personal stats.
5. **Process Timeline ("How We Work")**: Interactive 4-step workflow showcase (Define, Design, Build, Launch) with visual step counters and hover card effects.
6. **Projects Section**: Curated featured engineering projects showcasing title, category, description, tech stack tags, year, and live/GitHub external links.
7. **Luxury Footer**: Dark luxury footer with social links (GitHub, LinkedIn, Twitter), contact details, and copyright notice.
8. **Contact Modal**: Accessible popup modal for instant client/recruiter inquiries with form validation and confetti celebration on submit.

## Target Audience
- Technical recruiters and engineering hiring managers looking for top-tier FullStack & AI Engineers.
- Clients seeking luxury custom web applications, AI integrations, and high-performance WebGL/React platforms.
